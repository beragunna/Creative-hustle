THE CREATIVE HUSTLE - INSTALLABLE ANDROID APP (free, no Play Store needed)

This folder is a "Progressive Web App". Once it is put online, anyone can install it
on an Android phone from Chrome. It gets its own icon, opens full screen like an app,
and works offline after the first visit. Nothing here costs money.

FILES: index.html (the app), manifest.webmanifest, sw.js (offline), icons/ folder.

STEP 1 - Put the folder online for free (one time, about 10 minutes)
Option A: GitHub Pages
 1. Create a free account at github.com and sign in.
 2. Click New repository. Name it e.g. creative-hustle. Choose Public. Create it.
 3. Click "uploading an existing file". Drag in ALL files: index.html, manifest.webmanifest,
    sw.js and the whole icons folder. Click Commit changes.
 4. Open Settings > Pages. Under Branch choose main, folder /(root). Save.
 5. After a minute your link appears: https://YOURNAME.github.io/creative-hustle/
Option B: Cloudflare Pages or Netlify (both have free plans). Create a free account,
 choose to upload/drag-and-drop the folder, and you get a link.

STEP 2 - Install on a phone
 1. Open your link in Chrome on Android.
 2. Tap the menu (three dots) and choose "Install app" or "Add to Home screen".
 3. Confirm. The Creative Hustle icon now appears with the other apps.
 4. Open it once while online so it can save itself for offline use.
Share the link on WhatsApp so students can install it the same way.

UPDATING CONTENT LATER
 Replace index.html in your online folder. In sw.js change "creative-hustle-v1" to
 "creative-hustle-v2" so phones download the new version.

NOTE
 Student progress and notes are stored on each student's own phone only.
